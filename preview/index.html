Chrome extension

Copy a YouTube transcript with the Hebrew-brief prompt

This extension does not call an API. On a watch page it copies your conversion prompt plus the full caption transcript. You paste that into Claude Code or Codex, and that agent writes the Hebrew HTML file.

Load the unpacked extension

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked and select this repo folder
  4. Open a YouTube video that has captions
  5. Click Copy prompt + transcript on the page or in the popup
  6. Paste into Claude Code or Codex

What gets copied

  • The Hebrew brief prompt, including פרק בונוס — ליישום בעבודה
  • Video title, URL, id, and caption language
  • The full cleaned transcript

The agent should save a single RTL HTML file, not dump the page in chat. If a video has no captions, the extension says so instead of copying junk.
